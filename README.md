## Learning Approach

For each algorithm, I aim to understand:

1. What problem does it solve?
2. How does the algorithm work?
3. What assumptions does it make?
4. How do we implement it?
5. What hyperparameters does it have?
6. How do we evaluate it?
7. When should we use it?
8. What are its limitations?
9. How does it perform on real datasets?

The notebooks contain both conceptual explanations and practical implementations.
